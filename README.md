# Array Health: on-orbit element diagnosis and fault-compensated beams

**Live demo:** https://mohith26.github.io/cesiumastro-array-health/

An unofficial concept feature for a CesiumAstro payload console. It answers two questions an operator has once a phased array is on orbit:

1. **Which elements have changed since factory calibration, and by how much?** It solves every element's Tx and Rx gain and phase change from element-pair mutual-coupling telemetry, with 95% intervals, and separates dead Tx paths, dead Rx paths, weak amplifiers and phase drift.
2. **What weights restore the beam?** It re-solves the taper around the failed elements so the sidelobe mask holds at every steering direction out to 58.5 degrees, after 6-bit phase and 1 dB attenuator quantization, and reports what that costs in EIRP.

Unofficial concept demo by Mohith Gajjela. Not affiliated with CesiumAstro. Synthetic data.

## Result on the committed scenario (seed 20261105)

Simulated 288-element Ka-band T/R aperture (16 x 18 triangular lattice, 0.56 wavelength spacing, four tiles) with: two failed 4-channel beamformer ICs (8 elements, Tx and Rx dead), 3 dead PAs, 4 weak PAs (-2.1 to -4.8 dB), one dead LNA (Rx only), a thermal gradient across tile 2 (up to 38 degrees of phase walk and 1.2 dB droop), and 3 drifted phase shifters, on top of 0.2 dB / 2 degree residual errors everywhere.

| | Factory weights | Re-phase only | Compensated |
|---|---|---|---|
| Steering directions meeting the -24 dB mask (of 49) | 0 | 0 | **49** |
| Worst sidelobe vs. mask | +3.61 dB | +3.61 dB | -0.05 dB |
| Mean peak EIRP vs. a healthy array | -0.69 dB | -0.64 dB | -1.20 dB |

* Diagnosis vs. simulation truth: 11/11 dead Tx paths and 9/9 dead Rx paths found, no false alarms; RMS error 0.04 dB and 0.20 degrees over 277 live elements.
* Compensation costs 0.51 dB of EIRP on average across the scan field.
* "Re-phase only" (correct the measured drift and switch off dead elements, keep the factory taper) does not recover the mask, because the violations come from the holes the dead elements leave in the taper.

These numbers are regenerated by `node scripts/build.js` and recomputed live by the "Re-run in browser" button.

## How it works

**Telemetry and diagnosis** (`diagnose` in `core.js`). Each element transmits in turn while its neighbors in two rings receive. Dividing each on-orbit measurement by the same pair's factory baseline cancels the coupling coefficient, leaving `z_ij = g_i * h_j` (Tx change of i times Rx change of j). Dead paths are found first with a robust median of each element's ratios as transmitter and as receiver (below -15 dB). The remaining pairs give a linear system in log-amplitude and unwrapped phase, solved by weighted least squares (weights from the per-pair noise), with Huber reweighting and a gauge constraint. Standard errors come from the residual-scaled inverse normal matrix. Elements are classified as failed, degraded (gain interval entirely below -1 dB), drift (phase interval entirely beyond 8 degrees) or Rx-only fault.

**Scan-aware effective mask** (`effectiveMask`). Without the element pattern, steering is a pure shift in sine space, so one taper's relative pattern serves every direction. The element pattern breaks that: when the beam is scanned to 58.5 degrees, a sidelobe near broadside is about 3.7 dB stronger relative to the peak. The code folds every steering direction into one relative-coordinate mask, `M_eff(s) = M * min_d EP(d) / EP(d + s)`, so a single synthesis covers the whole field.

**Synthesis** (`synthesize`). Minimal change to the factory 32 dB Taylor taper: minimize `||w - w0||^2 + sum_s alpha_s |AF_s(w)|^2` subject to keeping the summed field, with adaptive (Olen-Compton style) weights `alpha_s` that grow on samples above the effective mask, rank-one updates of the Hermitian system and a complex Cholesky solve per iteration, and a projection onto each element's available gain (dead elements are zero, weak ones are capped).

**Certification** (`certify`, `run`). For each of 49 steering directions, the commands are formed from the estimated element gains, quantized (6-bit phase, 1 dB attenuator steps to 31 dB), and checked on an interleaved grid. This check first runs on the estimated hardware model only; if any direction fails, the design margin is raised and the taper re-solved. The reported results then radiate the same quantized commands through the simulated true hardware.

## Tests

`node --test test/core.test.js` (10 tests): real and complex Cholesky solves; the fast row-factorized pattern matches direct summation; steered uniform array peaks at N^2; steering is a pure sine-space shift; quantizer states; diagnosis finds every dead path on two seeds with RMS error under 0.1 dB / 0.5 degrees and the Rx-only fault is not mistaken for a Tx fault; effective mask behavior; the full pipeline passes all 49 directions; and **compensation never reads the simulation truth** (scrambling the truth leaves the synthesized weights bit-identical).

## Files

* `core.js`: all algorithms (UMD, runs in Node and the browser, no dependencies)
* `scripts/make_data.js`: seeded generator for `data/telemetry.json` (inputs) and `data/truth.json` (simulation truth, kept separate)
* `scripts/build.js`: runs the pipeline and writes `data/run.json` and `data/bundle.js`
* `index.html`, `style.css`, `app.js`: the page (static, no build step)

## Honest limitations

* Synthetic data from my own simple model, not CesiumAstro hardware. Coupling, noise levels, the element pattern (cos^1.3) and the failure mix are assumptions. The aperture size matches Vireo Ka 288's element count, and the 6-bit phase control matches what CesiumAstro has published for Nightingale 1 (64 phase states, 32 gain states); I assumed 1 dB attenuator steps.
* The telemetry model is mutual-coupling calibration on a T/R aperture. Vireo Ka 288 uses separate Tx and Rx AESAs, so there the same estimator would need a calibration-coupler path or ground-assisted measurements instead of element-to-element coupling.
* The -24 dB mask, main-lobe guard and scan grid are my choices, not a customer or regulatory spec. Certification is on sample grids (0.02 in sine space), not a continuous proof.
* The 95% intervals are slightly overconfident for gain on this seed (89% measured coverage, 98% for phase).
* EIRP is modeled as coherent field only; it ignores PA back-off efficiency, thermal effects of re-weighting, and the DC power not reclaimed from attenuated elements.
* Single-beam, single-frequency. A multi-beam payload would need the mask per beam and joint power limits per element.

## Novelty note

I could not find on-orbit element diagnosis or fault-compensated beam synthesis in CesiumAstro's public product pages (Vireo, Nightingale, Element, Space Systems, FAQ), press releases or the 2026 everything RF interview, which mentions factory and on-orbit calibration and telemetry as a focus. The underlying ideas are established: mutual-coupling calibration (Aumann, Fenn and Willwerth, 1989), re-optimizing beam coefficients after a PA failure (for example US10270524), and built-in-test-driven compensation (WO2009079174). What is new here is the combination as an operator feature: coupling ratios against the factory baseline with calibrated intervals, one scan-aware synthesis covering the full field, and certification of the quantized commands on the estimated model before anything is uplinked.
